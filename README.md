COVA | The State of Eternity 🔗
A minimalist, high-impact landing page for COVA, an urban streetwear brand. This project serves as the digital storefront and brand archive, bridging the gap between street culture and timeless fashion.

✨ Features
Minimalist UI: A sleek, high-contrast design that puts the brand identity first.
Brand Storytelling: Dedicated sections for the "Eternity" philosophy and "Born from the streets" narrative.
Visual Archive: A responsive 20-item image grid showcasing the latest drops.
Clean Navigation: Intuitive top-bar navigation and a bold "Enter Shop" call-to-action.
🛠️ Tech Stack
HTML5: Semantic structure for SEO and accessibility.
Vanilla CSS3: Custom styling (via style.css) focusing on modern typography and grid layouts.
Google Fonts: Integrated typography for a premium, editorial feel.
